# #74 Agent-Hires-Human Microtasks

> AI agents post verification micro-tasks to humans and pay them via PayPal/Venmo payouts on AI-checked completion.

**Theme:** E9 Agents as economic actors & B2B ops · **Group:** Agents as economic actors · **Crowding on Devpost:** Escrow cluster adjacent

## Problem statement
Agents need human verification (photos, calls) and humans need instant pay.

## Proposed solution
Task board + verification + Payouts.

## Target users
Agent builders; gig workers.

## AI contribution
Task decomposition, verification.

## PayPal integration
Payouts; Venmo.

**Primitives used** (see [[30 - Primitives Legend]]):
- `P11` Payouts (batch)
- `P12` Payouts to Venmo handles
- `A03` Intent and rationale reasoning (LLM-as-judge)
- `A13` Vision verification / evidence narrative

## Competitors and prior art
Payman, Amazon Mechanical Turk

Agent-pays-human platforms exist.
